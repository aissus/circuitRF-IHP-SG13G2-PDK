# Port map

Generated by `portmap.py` from the EM results in `results/`. Rerun it after an EM run.

Name is the port's index as P01, P02, ... Port is a drawn port label (with the schematic Term its SchematicId names) or a cut instance pin (path.pin, and its class from `explain --component-ports`). Net is the schematic net. Reference is what the port returns through. Co-sim node is the node of `<setup>_cosim.cnl` on that port, and the model terminal circuitRF put on it.
