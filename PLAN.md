# circuitRF-IHP-SG13G2: plan (set aside, 2026-11-05)

The IHP SG13G2 kit for circuitRF and its example workspaces, as a repository of their own. Nothing is
copied in yet. Today the kit lives in an IIC-OSIC-TOOLS-based sandbox: sources in `circuitrf-kit/`,
the built kit in `kits/IHP_SG13G2/`, and examples in `designs/IHP_kit_examples` and `designs/IHP_kit_demo`.

## Why a repository of its own, not a circuitRF pull request

circuitRF's `CLAUDE.md` bans the names of any PDK that does not come built into circuitRF. Its PDK
guide (`docs/user/src/reference/pdk-integration.md`) says real kits don't ship with circuitRF, and its
own docs call a SiGe kit "Kit A". The generic fixes found while building the kit go upstream as
separate branches in `../circuitRF`; the kit stays here.

## Layout

```text
generator/   <- circuitrf-kit/* (ihp2crf.py, ihp2va.py, qucs2csym.py, harmonica_ihp.py,
                validate_ihp_kit.py, va2cnl.py, build.sh, circuitrf-ihp-workspace)
examples/    <- ONE workspace: designs/IHP_kit_examples + the CE_10GHz_HB cell from designs/IHP_kit_demo
kit/         <- build output of generator/build.sh, git-ignored (cells, tech, models/osdi carry build paths)
README.md  LICENSE (Apache-2.0)  NOTICE  .gitignore
```

Examples to keep:
- **Qucs-S ports:** HBT_Ic, HBT_IcVce, HBT_fT_fmax, Resistors, MIM_Cap.
- **Load-pull:** HBT_Loadpull, plus the harmonica `.charm` documents (regenerated, see below).
- **EM:** inductor (EM) and inductor_TB (L/Q from all solvers).
- **From the demo:** CE_10GHz_HB.

Leave out (not sources, machine-local, or duplicates):
- **Machine-local:** `results/`, `.generated-cells/`, `.cwsuser`.
- **Regenerated by circuitRF:** `ihp-sg13g2-pcells/` (its `kitRoot` is absolute; circuitRF rewrites it on open).
- **One-off script:** `compare_Nx8.py` (container-only).
- **Duplicate:** `inductor/3d/inductor2.c3d` (a copy of `inductor.c3d`).
- **GPL-3.0 output:** `inductor/gds2palace/`.
- **From the demo:** the stray cell `hhhh/`, the bare `netlist.cnl`, and the duplicate `tech/` and `harmonica/`.

## Absolute paths to replace

Everything below points into the container (`/foss/...`) and only resolves under the sandbox's mounts:

| What | Where |
|---|---|
| `LibraryRefs` | `IHP_kit_examples/.cws:4`, `IHP_kit_demo/.cws:4` |
| kit `CellRef`s | `HBT_Ic`, `HBT_IcVce`, `HBT_fT_fmax`, `HBT_Loadpull`, `MIM_Cap` schematics (line 25 or 57); `Resistors.csch:77,140,203`; `CE_10GHz_HB.csch:25` (climbs `../` ten times) |
| model `File=` | kit cells `npn13G2{,l,v}` (`vbic_1p3_5t.osdi`), `rsil`/`rppd`/`rhigh` (`r3_cmc.osdi`) |
| `.charm` | every file: `Provider` (line 6), `ModelFile` (line 8) |
| scripts | `build.sh:12,28`, `ihp2crf.py:4,527`, `harmonica_ihp.py:26-27,48,179`, `validate_ihp_kit.py:4,251`, `circuitrf-ihp-workspace:14-15` |
| docs | examples `README.md:3,25,36,62,172` |

How each gets fixed:
- **`CellRef`/`LibraryRefs`:** relative to `../kit/IHP_SG13G2`. Relative `CellRef` already works (the demo climbs `../`). Check relative `LibraryRefs` with `circuitrf cli check`; if it is refused, use a `${...}` path token (`PathTokens.cs` upstream).
- **`build.sh`:** `K` defaults to `<repo>/kit/IHP_SG13G2`, a one-line change. It passes that absolute `--osdi` dir to `ihp2crf.py`, and regenerates the 8 `.charm` files into `examples/harmonica/` with `harmonica_ihp.py charm` (git-ignored: they carry absolute model paths).
- **`PdkRefs`:** stays `/foss/pdks/ihp-sg13g2`, documented as the one machine path. Only `HBT_layout` and the palette need it.

## Licensing

- **Repository:** Apache-2.0, the same as the IHP PDK.
- **NOTICE** credits:
  - the IHP PDK Authors (Apache-2.0): model expressions, layer table, ITF stackup, inductor PCell geometry;
  - the Qucs-S `user_lib` symbols (Mike Brinson);
  - R3 CMC (ECL-2.0, Si2), in the built kit only;
  - VBIC 1.3 from VACASK, in the built kit only.
- **VBIC-derived `.osdi` are built, never committed.** The `vbic_1p3.va` in VACASK has no license header and VACASK is AGPL-3.0, so the repo carries only the scripts that build them.
- **No GPL-3.0 material.** The PDK's `libs.tech/palace` is GPL-3.0. Today it supplies the `.ctech` EM stackup (`workflow/SG13G2_200um.xml`), the inductor GDS and the gds2palace `.s2p`. Both get replaced:
  - **Stackup:** `ihp2crf.py`'s tech step (`ihp2crf.py:408-467`) reads `libs.tech/parasitics/itf/sg13g2_typ.itf` (Apache-2.0: per-layer THICKNESS, ER and RPSQ, giving σ = 1/(RPSQ·t)). Substrate and EPI values come from `libs.doc/doc/SG13G2_os_process_spec.pdf`, cited in a comment. Print the old and new z-positions side by side once as a sanity check.
  - **Inductor:** drawn from IHP's Apache KLayout PCell (`libs.tech/klayout/python/sg13g2_pycell_lib/ihp/inductors_code.py`) at the old 500 pH geometry. Write a GDS with KLayout, `circuitrf cli import` it into `examples/inductor/layout`, and redraw the two ports. Run Palace, openEMS and EMerge once (Palace as a batch job if slow); L should agree with the old run within a few %. No tuning.

## Verification

Builds run inside the JKU image, so ngspice, Xyce, openvaf, VACASK and circuitRF are all there.
They write only into this repository.

- `generator/build.sh` gives validation 120/120 and `circuitrf cli check` on every cell.
- `circuitrf cli check` on every example bench.
- Run CE_10GHz_HB once and compare it with the sandbox's `designs/IHP_kit_demo/results`.
- A search of the committed tree for absolute paths (container mounts, home and project directories, host names) finds only the documented PdkRef and a "Using it in the JKU image" README section.

The kit was built and validated with circuitRF 1.6.0 (`kits/IHP_SG13G2/BUILD`). Re-validate it on
whatever circuitRF the image carries when this resumes.
